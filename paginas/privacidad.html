Política de privacidad

Secretaria · actualizada el 19 de octubre de 2026 · volver al inicio

Qué es Secretaria

Secretaria es un proyecto personal de código abierto. Su responsable es Guillermo Garcia Andugar. Funciona en un servidor privado suyo y trata únicamente los datos de su propia cuenta de Google y de su propio WhatsApp. No es un servicio abierto al público.

Qué datos de Google usa y para qué

  • Google Calendar: crear, leer, modificar y borrar eventos del calendario del usuario, para reflejar las citas que él pide por WhatsApp (y las que cambia a mano).
  • Google Drive: crear carpetas, subir, mover y leer los archivos de una carpeta del propio usuario, para guardar y ordenar los archivos que envía por WhatsApp, y mandar a la papelera de Drive las carpetas o archivos que el usuario pide borrar, solo después de enseñarle la lista y de que lo confirme.

Solo se accede a esos datos para esas funciones. No se usan para publicidad, no se venden y no se comparten con terceros. El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Qué otros datos se tratan

  • Mensajes de WhatsApp del usuario (texto, transcripción de sus audios y archivos adjuntos), recibidos a través de la API de WhatsApp Cloud de Meta.
  • El texto de cada mensaje se envía a la API de Gemini de Google para entender qué se pide. Las transcripciones de audio se hacen igual.
  • Los datos ya clasificados (tareas, notas, listas, citas, proyectos) y los datos que el usuario le cuenta para que los recuerde (por ejemplo, su horario semanal o cómo quiere que le llame) se guardan en una base de datos de Supabase en la Unión Europea, con acceso restringido.

Quién puede verlos

Solo el usuario y los servicios que acaban de nombrarse, que actúan por cuenta suya. No se ceden datos a nadie más.

Cuánto tiempo se guardan

Hasta que el usuario los borra (por WhatsApp, en Supabase, en Google Calendar o en Google Drive) o deja de usar Secretaria.

Cómo retirar el acceso o borrar los datos

  • El acceso a Google se retira en myaccount.google.com/permissions, eliminando la app Secretaria.
  • Los datos de Calendar y de Drive son del propio usuario y los puede borrar en esos servicios. El resto (mensajes, tareas, notas) se borra a petición del usuario por WhatsApp o directamente en su base de datos de Supabase.

Cambios

Si esta política cambia, se actualizará esta página y su fecha.
